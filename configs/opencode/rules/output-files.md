# One-time Output: File or Chat

When the output is **one-time** — a single list, draft, note, or answer that
isn't ongoing project code — ask the user whether to save it to a file or keep
it in the chat.

## When to ask

- The content is only needed now: no repeated use, no repo maintenance.
- Examples: a one-off list, a quick draft, a scratch answer, a temporary note.
- Ask **before** creating a file — don't spawn files unprompted for one-off
  content.

## How to ask

Offer both options, e.g.:

> Save this to a file (tell me the path), or keep it in chat?

- **File**: confirm the path, follow the project's location/naming conventions.
- **Chat**: output it in the conversation only — no file written.

## When not to ask

Ongoing content that belongs in the repo (source code, configs, docs meant to
be maintained) doesn't need the check — create it directly.
